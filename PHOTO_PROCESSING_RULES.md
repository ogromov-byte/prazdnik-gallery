# Правило обработки новых фотосессий для objecta.art

Действует для каждой новой фигурки после получения ZIP-архива с фотосессией.

## 1. Приёмка ZIP
- Распаковать архив, проверить количество файлов, разрешение, резкость, цвет, прозрачность, полноту фигурки и равномерность ракурсов.
- Сохранить все оригиналы без изменений. Никакого повторного автоматического удаления фона, если фигурки уже вырезаны.
- Сделать контактный лист и выбрать главный кадр, три дополнительные фотографии и последовательность для вращения 360°.
- Если качество кадров недостаточно, сообщить об этом до публикации.

## 2. Главное фото: /showcase
- Для каждой фигурки предлагается **один главный премиальный showcase-кадр** для карточки и, при необходимости, главной страницы.
- Обработка /showcase только после **прямого разрешения Олега на применение к конкретной фотографии**. Не запускать генератор или генеративное редактирование автоматически по факту получения ZIP.
- Принцип подачи: единый для всей коллекции согласованный светлый или другой утверждённый фон, мягкий предметный свет, естественная контактная тень, премиальный студийный вид.
- Запрещено менять силуэт, пропорции, лицо, прическу, детали, фактуру ручной росписи, цвет работы и форму подставки. Сверять результат с оригиналом; если достоверность нарушена — отказаться от результата /showcase и использовать детерминированную коррекцию исходного снимка.
- Фон, освещение и масштаб должны быть согласованы между всеми фигурками коллекции. Не менять уже утверждённый стиль без согласования.

## 3. Три дополнительных ракурса
- Отобрать три информативных снимка, показывающих разные стороны фигурки. Обычно: профиль справа, вид сзади, профиль слева; состав уточняется по фотосессии.
- Только детерминированная обработка: баланс белого, экспозиция, цветопередача, аккуратная чистка артефактов и одинаковое размещение.
- Не применять /showcase и не дорисовывать элементы без отдельного согласования.

## 4. Вращение 360°
- Использовать **последовательные реальные кадры фотосессии** в верном порядке. Не синтезировать промежуточные ракурсы.
- Поддерживать одинаковую высоту, масштаб, положение центра и ровную базовую линию; не искажать сам предмет.
- Оптимизировать кадры для быстрой загрузки (например, WebP), сохранив исходники и мастер-файлы.
- Управление мышью и пальцем; не показывать стрелки в режиме 360°, согласно правилу карточки.
- Проверять непрерывность оборота и отсутствие скачков при переходе от последнего кадра к первому.

## 5. Карточка товара и публикация
- В карточке одна большая фотография и миниатюры остальных доступных снимков; текущий кадр не дублируется внизу, подписи градусов не показывать.
- Вращение 360° — отдельный режим. Соблюдать согласованную типографику, масштаб работы, фон и компоновку сайта.
- Сохранить исходники и оптимизированные версии в структурированной папке фигурки; проверить пути к каждому файлу.
- Проверить карточку на компьютере и телефоне, затем внести изменения в GitHub `ogromov-byte/prazdnik-gallery`.
- Не изменять другие части сайта без необходимости.

## 6. Обязательная последовательность
ZIP → проверка и отбор → запрос разрешения на /showcase главного кадра → обработка главного кадра (при разрешении) → подготовка 3 документальных ракурсов → реальный 360° → оптимизация → интеграция → проверка → коммит в GitHub.

**Основной принцип:** художественная подача одного главного кадра не должна подменять точную демонстрацию реальной авторской работы.
