# Праздник — сайт-магазин фигурок Владимира Гвоздева

Статический сайт-магазин девяти фигурок Владимира Гвоздева.
Чистые HTML/CSS/JS, без сборщиков, фреймворков и npm.

- Домен: prazdnik-gallery.ru
- Хостинг: Beget (shared-хостинг, выкладка по SSH)
- Продавец: отдельное ООО, которое ещё регистрируется

## Статус: сайт НЕ публичный

Пока ООО не зарегистрировано, на домене стоит только заглушка из `stub/`
с запретом индексации. Сайт целиком на хостинг не выкладывать.
Переключение выкладки на сайт (переменная `DEPLOY_DIR` в
`.github/workflows/deploy.yml`) — только по прямому указанию владельца.

## Фирменный стиль

- Шрифт: Golos Text
- Цвета:
  - ink `#1C1B19` — основной текст
  - clay `#9E3F27` — акцент
  - wall `#F6F4F0` — фон

Новые цвета и шрифты не добавлять без согласования.

## Структура файлов

```
/                       — файлы сайта (HTML, CSS, JS, изображения)
stub/                   — заглушка, которая сейчас стоит на домене
  index.html            — страница «Сайт готовится к открытию», meta noindex
  robots.txt            — Disallow: /
  .htaccess             — заголовок X-Robots-Tag: noindex
.github/workflows/
  deploy.yml            — выкладка на Beget при пуше в main
CHANGELOG.md            — история версий сайта
CLAUDE.md               — этот файл
```

## Выкладка

- Пуш в `main` запускает `.github/workflows/deploy.yml`: содержимое папки
  `DEPLOY_DIR` (сейчас `stub`) копируется через rsync в `public_html` на Beget.
  rsync работает с `--delete`: всё, чего нет в папке, на хостинге удаляется
  (кроме `.well-known/`).
- Доступы — только через GitHub Secrets: `BEGET_SSH_HOST`, `BEGET_SSH_USER`,
  `BEGET_SSH_KEY`, `BEGET_SSH_KNOWN_HOSTS`, `BEGET_DEPLOY_PATH`.
  Ключи, пароли и логины в репозиторий не коммитить никогда.
- Пока на домене заглушка, у неё обязательно должны оставаться meta
  `noindex`, `robots.txt` с `Disallow: /` и `.htaccess` с `X-Robots-Tag`.

## Правила работы

- Каждая правка — отдельный коммит с понятным описанием на русском:
  первая строка — что сделано («Исправлена цена фигурки „Ёлка“»),
  при необходимости ниже — зачем.
- Не смешивать в одном коммите несвязанные изменения.
- Заметные изменения сайта записывать в `CHANGELOG.md`.
- Без сборщиков и зависимостей: сайт должен открываться как есть,
  из файлов.
- Проверять, что страницы корректно выглядят на ширине телефона.
