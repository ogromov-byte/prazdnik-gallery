# Праздник: сайт-магазин фигурок Владимира Гвоздева

Статический сайт-магазин девяти фигурок Владимира Гвоздева.
Чистые HTML/CSS/JS, без сборщиков, фреймворков и npm.

- Домен: prazdnik-gallery.ru
- Хостинг: Beget (shared-хостинг, выкладка по FTP)
- Продавец: отдельное ООО, которое ещё регистрируется

## Статус: сайт НЕ публичный

Пока ООО не зарегистрировано, на домене стоит только заглушка из `stub/`
с запретом индексации. Сайт целиком на хостинг не выкладывать.
Переключение выкладки на сайт (переменная `DEPLOY_DIR` в
`.github/workflows/deploy.yml`) только по прямому указанию владельца.

## Фирменный стиль

Источник: брендбук «Галерея Громовой», версия 1.1, файл
`/08 Брендбук/Галерея Громовой — брендбук.pdf` в Dropbox. Если правила
здесь расходятся с брендбуком, прав брендбук.

- Шрифт: Manrope, одна гарнитура на всё. Заголовки начертанием 300, текст 400,
  интерфейс 500, короткие рубрики прописными 600 с разрядкой +0,12 em.
  Курсив и подчёркивание не используются, выделение только весом.
- Цвета:
  - wall `#F6F4F0`: основной фон
  - paper `#FFFFFF`: карточки и плашки
  - ink `#1C1B19`: текст, логотип
  - graphite `#5C5852`: вторичный текст
  - line `#DCD7CF`: разделители
  - stone `#A8A196`: только для не-текстовых элементов
  - clay `#9E3F27`: акцент, отметка «продано»
  - clay-soft `#EFE3DC`: фон анонсов и цитат
- clay появляется не больше одного раза на экране. На сайте это кнопка покупки.
- Сетка с шагом 8 px. Углы прямые, скругление 2 px только у кнопок и полей ввода.
- Фотографии произведений не обрезать, не класть на них текст и фильтры.
  Если формат не совпадает, добавлять поля цвета wall.
- Тексты: без восклицательных знаков, эмодзи и слов «шедевр», «уникальный»,
  «успейте». Имя художника при первом упоминании полностью, дальше по фамилии.
  Названия произведений и выставок в кавычках-ёлочках.
- Имена покупателей не публикуются никогда.

Новые цвета и шрифты не добавлять без согласования.

## Структура файлов

```
/                       # файлы сайта (HTML, CSS, JS, изображения)
stub/                   # заглушка, которая сейчас стоит на домене
  index.html            # страница «Сайт готовится к открытию», meta noindex
  robots.txt            # Disallow: /
  .htaccess             # заголовок X-Robots-Tag: noindex
.github/workflows/
  deploy.yml            # выкладка на Beget при пуше в main
CHANGELOG.md            # история версий сайта
CLAUDE.md               # этот файл
```

## Выкладка

- Пуш в `main` запускает `.github/workflows/deploy.yml`: содержимое папки
  `DEPLOY_DIR` (сейчас `stub`) копируется по FTP (lftp mirror, только с TLS)
  в `public_html` на Beget. Выкладка идёт с `--delete`: всё, чего нет в папке,
  на хостинге удаляется (кроме `.well-known/`).
- Доступы только через GitHub Secrets: `BEGET_FTP_HOST`, `BEGET_FTP_USER`,
  `BEGET_FTP_PASSWORD`, `BEGET_FTP_DIR`.
  Ключи, пароли и логины в репозиторий не коммитить никогда.
- Пока на домене заглушка, у неё обязательно должны оставаться meta
  `noindex`, `robots.txt` с `Disallow: /` и `.htaccess` с `X-Robots-Tag`.

## Правила работы

- Стиль всех текстов (чат, сайт, коммиты, комментарии): навык
  `.claude/skills/human-style/SKILL.md`. Главное: никаких длинных тире,
  человеческий язык без штампов.

- Каждая правка идёт отдельным коммитом с понятным описанием на русском.
  В первой строке написано, что сделано («Исправлена цена фигурки „Ёлка“»),
  ниже при необходимости объясняется зачем.
- Не смешивать в одном коммите несвязанные изменения.
- Заметные изменения сайта записывать в `CHANGELOG.md`.
- Без сборщиков и зависимостей: сайт должен открываться как есть,
  из файлов.
- Проверять, что страницы корректно выглядят на ширине телефона.
