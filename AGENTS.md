# Постоянные рабочие инструкции проекта objecta.art

## GitHub: основной способ работы
- Основной репозиторий сайта фигурок: `ogromov-byte/prazdnik-gallery`; рабочая ветка: `main`.
- В рамках этого проекта подключение GitHub к ChatGPT уже было настроено и подтверждено: чтение и запись в репозиторий работали.
- **При каждой задаче по сайту сначала проверить доступные GitHub-инструменты и права на конкретную операцию.** Не отвечать автоматически, что доступа к GitHub нет.
- Для правок текстовых файлов: прочитать текущую версию из репозитория, исправить, сохранить непосредственно в GitHub, проверить результат, дать ссылку на изменённый файл или коммит.
- Не перекладывать на Олега ручное скачивание, загрузку, копирование кода и коммиты, если операция выполнима через доступные инструменты.
- Для двоичных изображений и массовых изменений проверить поддержку GitHub blob/tree/commit API. Если конкретный способ загрузки недоступен или операция завершилась ошибкой, назвать точную причину и предложить минимальный обходной путь. Не путать ограничения отдельных операций с отсутствием доступа к репозиторию.
- Запрашивать подтверждение, только когда оно действительно необходимо, а не повторно для уже согласованных изменений.
- Не объявлять изменение внесённым до успешного коммита. После записи проверять, что файл существует в ветке.
- Если подключение в будущем пропадёт, **сначала попытаться проверить его заново**, а затем сообщать о подтверждённом препятствии.

## Обработка фото и карточек
- Следовать файлу `PHOTO_PROCESSING_RULES.md`: 6 обработанных фотографий в карточке и отдельные 24 исходных последовательных кадра 360°.
- Генеративная обработка `/showcase` главного кадра допускается только после прямого разрешения Олега; без изменения самой фигурки.
- Беречь утверждённый дизайн, не менять незаказанные компоненты сайта.

Эти инструкции созданы по прямой просьбе владельца проекта, чтобы работа шла непосредственно в GitHub, а не перекладывалась на пользователя.
