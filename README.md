# prazdnik-gallery

## Стандарт фотографий коллекции «Праздник»

Правило утверждено для текущей главной страницы и **всех будущих фотосессий**.

1. **Масштаб:** ориентир высоты тела с головой в карточке товара — 720 px на десктопе. Уши, головные уборы, прочие выступающие детали не входят в эти 720 px и размещаются дополнительно. Не уменьшать тело для вписывания ушей.
2. **Главная страница:** героев внутри одного ряда выравнивать **по линии коленей**, а не по вершинам голов, ушам или нижней границе исходного файла. Разная высота головных уборов и ушей допустима.
3. **Калибровка:** для каждого нового фронтального кадра отдельно определять линию коленей и задавать персональное вертикальное смещение изображения, сохраняя существующий масштаб и ширину сетки. Для нестандартных поз (сидящие фигуры) ориентироваться на анатомическую линию коленей, а не на подставку.
4. **Первый ряд, базовая калибровка 13.10.2026:** Снежинка 0 px; Зайчик −12 px при исходном увеличении 1.08; Моряк −30 px (правила в `index.html`, стиль `collection-knee-line-20261013`). Это предварительные оптические поправки для нынешних снимков; после поступления качественных фотографий проверить ещё раз.
5. **Обработка:** применять только исходные фотографии / детерминированную обработку без генерации и без повторного вырезания объектов. Сохранять полную геометрию фигуры, включая подставку.
6. **Карточка товара:** четыре ключевых ракурса, при наличии фотосессии отдельный режим 360°. Переключение не должно изменять общий размер страницы или обрезать выступающие детали.
7. **«Вы недавно смотрели»:** использовать актуальный фронтальный кадр товара. Не менять общую сетку ради одной фигурки.

Новые снимки добавляются с сохранением этой системы; для каждого героя проводится контроль на десктопе и мобильном экране.
