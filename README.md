# prazdnik-gallery

Сайт коллекции фигурок «Праздник».

## Единый обязательный стандарт

**[FIGURINE_ADDING_SKILL.md](FIGURINE_ADDING_SKILL.md)** — единственный нормативный документ по подготовке фотографий, размерам, главной странице, карточке товара, режиму 360°, лупе и проверке качества.

**Эталон карточки товара:** [Пьеро](piero.html).

Другие файлы, старые CSS-комментарии и история обсуждений не устанавливают новые технические требования и не отменяют этот стандарт.

## Порядок работы

Обрабатывать и утверждать по одной фигурке. Сохранять исходные фотографии и рабочие пути до безопасной замены. Зайчика не трогать: он идёт отдельным этапом последним.

При изменении стандарта редактировать только `FIGURINE_ADDING_SKILL.md`, не дублируя числовые нормы в README.
